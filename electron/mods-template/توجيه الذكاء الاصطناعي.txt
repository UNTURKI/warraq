أنت تصنع «مودًا» لبرنامج «ورّاق»: برنامجٌ عربي لسطح المكتب (Windows، مبنيٌّ على Electron وصفحات HTML) لإخراج كتب التراث وقراءتها. المود يغيّر شكل البرنامج أو أصواته أو حركته، أو يضيف إليه ما ليس فيه، ويعمل داخل صفحاته بـ CSS و JavaScript. اقرأ هذا كله ثم اصنع ما أطلبه في آخره.

══════════ كيف تجيب ══════════
١. إن كان في طلبي غموضٌ يغيّر العمل كثيراً فاسألني سؤالاً أو سؤالين أولاً، وإلا فاصنع المود مباشرة.
٢. ضع ملفات المود كلها في **كتلة كودٍ واحدة فقط** (يُنسخ كلّه بزرّ نسخٍ واحد ويُلصق في البرنامج فيفهمه). افتح الكتلة بأربع علامات ```` وأغلقها بأربع، وفي داخلها كل ملفٍ بعد سطر عنوانه بالضبط هكذا، ثم «=== END ===» في آخرها:

````text
=== FILE: mod.json ===
{
  "id": "…"
}
=== FILE: mod.js ===
export default function (wq) {
  …
}
=== FILE: mod.css ===
…
=== FILE: icon.svg ===
<svg …>…</svg>
=== END ===
````

٣. داخل الكتلة: لا كتل كود أخرى (لا ``` في أول أي سطر)، ولا كلام غير الملفات. ولا يبدأ سطرٌ في ملفٍ بـ «=== FILE:».
٤. اكتب كل ملفٍ كاملاً، لا «… بقية الكود كما هو» ولا اختصار. وإن عدّلتَ مودًا في ردٍّ لاحق فأعد كتلة الملفات كلها كاملةً بالطريقة نفسها (لا الملف الذي تغيّر وحده).
٥. الصور والرسوم: ارسمها بـ SVG (ملف ‎.svg‎ نصيٌّ يُكتب في الكتلة) أو بـ CSS. والأصوات: ولّدها في الكود بـ Web Audio (wq.audio). وإن لزم ملفٌ لا يُكتب نصاً (صورة فوتوغرافية، تسجيل صوت، خط) فضعه في المجلد assets/ (مثل assets/fire.mp3)، واذكر بعد الكتلة: «أضف هذه الملفات: …» ليرفقها المستخدم بنفسه.
٦. بعد الكتلة: سطران بالعربية: ما يفعله المود، وأين يُرى في البرنامج.

  "name": "سراجٌ يتّقد",           ← اسمه بالعربية
  "version": "1.0.0",
  "author": "",

  "icon": "icon.svg",             ← اختياري (svg/png)

الأجزاء (كل جزءٍ صفحة):
- shell: الهيكل — شريط العنوان، والشريط الجانبي بالأبواب، وشريط الحالة، ومكان الأبواب، ومجلس الدرس (/desk/)
- khizana: الخزانة (رفوف الكتب المخرجة) · bench: المِنضدة (إخراج كتاب: البحث، والمجلدات، والتنضيد، والغلاف) · muharrir: المحرِّر
- rahl: الرَّحل (قارئ PDF بكتابٍ مجسّم تُقلَّب أوراقه) · styles: الأساليب · covers: المجلِّد (الأغلفة) · settings: نافذة الإعدادات · other: غيرها
كل بابٍ صفحةٌ في إطار (iframe[data-door="rahl"]…) داخل الهيكل ومن الأصل نفسه؛ فالمود في shell يصل إلى صفحات الأبواب كلها إن شاء (wq.win('rahl')).

══════════ mod.js ══════════
وحدة ES تُصدِّر دالةً تأخذ wq، وترجع (إن شئت) دالةً تُنادى حين يُطفأ المود:

export default function (wq) {
  if (wq.part !== 'shell') return;
  const b = wq.add('<button type="button" class="door tool" title="زرّي"><span>زرّي</span></button>', '.side', document.querySelector('.side .sp'));
  wq.on(b, 'click', () => wq.toast(wq.settings.text));
  wq.onSettings(() => { /* أعد الرسم بالإعدادات الجديدة */ });
}

أدوات wq (كل ما يُضاف بها يزول وحده حين يُطفأ المود، فيُطفأ ويُشعل بلا إعادة تحميل — فاستعملها دائماً):
- wq.id، wq.name، wq.part (الجزء الذي يعمل فيه الآن)، wq.settings (القيم)، wq.onSettings(fn)
- wq.url('assets/a.png') ← عنوان ملفٍ من ملفات المود
- wq.css(text) ← يضيف أنماطاً · wq.html(markup) ← عنصر · wq.add(عنصر أو html، مكان؟ (عنصر أو محدِّد؛ الأصل body)، قبلَ؟) ← العنصر
- wq.on(عنصر، حدث، fn، خيارات؟) ← مستمع · wq.on('door' | 'bench' | 'night', fn) ← أحداث البرنامج
    door ← { door, from } (تغيّر الباب الظاهر) · bench ← { id, title, running, pct, stage, done } أو null · night ← true/false (السِّراج)
- wq.timeout(fn, ms)، wq.interval(fn, ms)، wq.frame((t, dt) => …) ← حلقة رسمٍ كل إطار (ترجع false فتتوقف)
- wq.observe(عنصر، fn، خيارات؟) · await wq.when(محدِّد) ← أول عنصرٍ يطابق (الآن أو حين يظهر) · wq.each(محدِّد، fn) ← لكل عنصرٍ يطابق الآن وكلما ظهر جديد
- wq.sound('assets/a.mp3', { volume, loop, rate }) · wq.audio ← AudioContext · await wq.buffer('a.wav') ثم wq.play(buf, { volume, rate, loop })
- wq.store.get(k, أصل)، wq.store.set(k, v) ← حفظٌ صغير في الجهاز · wq.toast(نص) ← رسالةٌ قصيرة
- wq.door (الباب الظاهر)، wq.doors، wq.go('rahl') ← يفتح باباً، wq.win('bench') ← نافذة باب
- wq.night، wq.setNight(true) ← السِّراج
- wq.command({ title, keys?, run }) ← أمرٌ في «القلم» (Ctrl+K)
- await wq.api('/api/…') ← طلبٌ إلى خادم البرنامج الداخلي
- wq.shell (واجهة الهيكل WarraqShell)، wq.desk (جسر البرنامج warraqDesktop) ← لمن أراد كل شيء
- wq.cleanup(fn) ← ما يُفعل حين يُطفأ · wq.log(…)، wq.error(نص) ← خطأٌ يُكتب في «الطِّراز» تحت اسم المود

══════════ ما في البرنامج ══════════
الهيكل (shell):
- .tbar: شريط العنوان (الأعلى) · .status: شريط الحالة (الأسفل)
- .side: الشريط الجانبي (على اليمين)، فيه أزرار الأبواب ‎.side .door[data-door="khizana|bench|muharrir|rahl|styles|covers|tiraz"]‎، ثم ‎.side .sp‎ (فراغ)، ثم زرّ السِّراج ‎.side [data-lamp]‎ (aria-pressed) و #settingsBtn
  وكل زرٍّ فيه svg (24×24) ثم span باسمه؛ وزرٌّ تضيفه بالشكل نفسه: <button class="door tool"><svg…/><span>اسمه</span></button>
- #doors: مكان الأبواب (position: relative)، فيه iframe لكل باب؛ ومودٌ يضع فوقها لوحةً كاملة يضعها فيه (position:absolute; inset:0; z-index:6)
- #lesson: مجلس الدرس
- ألوان البرنامج متغيّرات CSS في كل صفحة: --paper (الورق) --vellum --sheet --ink (الحبر) --rubric (العنابي) --gold --gold-d --line --muted --btn --on-rubric، والخطّان --display (العناوين) و --ui (الواجهة)
- السِّراج (الوضع الليلي): الصنف night على html (ذهبٌ على لازورد)؛ فاجعل ما تصنعه حسناً في الوضعين.

══════════ قواعد ══════════
- البرنامج يعمل بلا إنترنت: لا تحمّل شيئاً من الإنترنت ولا مكتبات من CDN (لا three.js ولا غيره). إن احتجت شيئاً فاكتبه بنفسك (CSS 3D، Canvas، SVG، Web Audio كلها متاحة).
- لا eval ولا new Function، ولا تغيّر ملفات الكتب أو إعدادات البرنامج إلا إن طلبتُ ذلك صراحة.
- الواجهة عربية من اليمين إلى اليسار؛ وكل نصٍّ تضيفه بالعربية الفصيحة.
- لا تُخفِ ما يحتاجه المستخدم للخروج: زرّ «الطِّراز» في الشريط الجانبي.
- صفحات البرنامج تُرسم بعد تحميلها وبعضها يُعاد رسمه: استعمل wq.when و wq.each لا querySelector وحده.
- لا تطل العمل في حلقةٍ واحدة (يتجمّد البرنامج)؛ ووزّع الحركة على wq.frame، واحترم prefers-reduced-motion.
- اجعل في settings ما يفيد المستخدم أن يغيّره (الصوت، اللون، الشدة، الإظهار والإخفاء).
- الحجم كله حتى ٩٦ م.ب.
