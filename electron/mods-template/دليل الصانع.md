# دليل صانع المودات

المود حُلّةٌ تُلبسها البرنامج: يغيّر شكله (ألوانه، خطوطه، حدوده)، أو أصواته وحركته، أو يضيف إليه ما ليس فيه (زرّاً، لوحةً، باباً جديداً، داراً ثلاثية الأبعاد تمشي فيها). يكتبه أي أحدٍ يعرف HTML و CSS و JavaScript، ويُشارَك ملفاً واحداً ‎.wqmod‎.

> المود يعمل داخل البرنامج بكامل ما لواجهته: يرى صفحاتها ويغيّرها، ويصل إلى جسر البرنامج (حفظ الملفات، والخزانة…). فاصنع لمن يثق بك، وثبّت ممن تثق به.

## البدء في دقيقة

- من «الطِّراز» اضغط **اصنع مودًا**: يُنشأ مجلدٌ في «المستندات ← الورّاق ← مودات» فيه هذا القالب، ويُفتح، ويعمل المود **قيد الصنع**.
- عدّل `mod.js` أو `mod.css` واحفظ: يُعاد المود في البرنامج في الحال، بلا إعادة تشغيل.
- أخطاء نصّك تظهر في «الطِّراز» تحت اسم مودك (ومعها الجزء الذي وقعت فيه). و«أدوات المطوّر» من قائمة «عرض».
- حين يتم: من قائمة المود في «الطِّراز» **صدّره للمشاركة** ← ملف ‎.wqmod‎ تُرسله لمن شئت؛ يفتحه فيُسأل قبل تثبيته.

## بالذكاء الاصطناعي

من «الطِّراز» اضغط **بالذكاء الاصطناعي**: انسخ التوجيه الجاهز (فيه كل ما في هذا الدليل بلغة يفهمها الذكاء الاصطناعي)، وألصقه في محادثةٍ مع ChatGPT أو Claude أو Gemini، واكتب تحته ما تريد. والتوجيه يطلب منه أن يضع الملفات كلها في **كتلة كودٍ واحدة** (كل ملفٍ بعد سطر `=== FILE: الاسم ===`)، فتنسخها بزرّ النسخ الذي عليها و**تلصقها** في الخانة نفسها: يستخرج البرنامج الملفات منها ويعرض المود قبل تثبيته (ويفهم أيضاً الردّ كله بكلامه، أو ملفاتٍ في كتلٍ متفرقة بعد `FILE: الاسم`). وما لا يُكتب نصاً (صورٌ فوتوغرافية، أصواتٌ مسجّلة، خطوط) يُرفق بزرّ «أرفق ملفات» فيوضع حيث يذكره المود (أو في `assets/`)، ويقول لك البرنامج إن ذكر المود ملفاً لم تُرفقه. وإن أعطاك الذكاء الاصطناعي ملفاً مضغوطاً أو مجلداً فاسحبه إلى «الطِّراز» كأي مود.

## mod.json

```json
{
  "id": "lamp-fire",
  "name": "سراجٌ يتّقد",
  "version": "1.0.0",
  "author": "اسمك",
  "description": "سطرٌ أو سطران يقرؤهما من يثبّته",
  "icon": "icon.svg",
  "preview": "preview.png",
  "homepage": "https://…",
  "parts": ["shell"],
  "js": ["mod.js"],
  "css": ["mod.css"],
  "settings": [],
  "reload": false
}
```

| الحقل | ما هو |
|---|---|
| `id` | معرّفٌ لا يتكرر: حروفٌ لاتينية صغيرة وأرقام و `-` `_` `.` (من ٢ إلى ٦٤). تحديث المود يكون بالمعرّف نفسه ورقمٍ أعلى |
| `name` و `description` و `author` و `version` | ما يُعرض في «الطِّراز» وعند التثبيت |
| `icon` و `preview` | اختياريان: أيقونة (svg/png) وصورةٌ للبطاقة (png/jpg/webp/gif) |
| `parts` | أين يعمل: قائمةٌ من الأجزاء (الجدول تحت)، أو `"*"` لكلها |
| `js` و `css` | ملفاته (واحدٌ أو أكثر) |
| `settings` | إعداداتٌ تظهر للمستخدم في «الطِّراز» (تحت) |
| `reload` | `true`: حين يُطفأ تُعاد صفحاته (لمن لا يستطيع أن يزيل أثره وحده). والأفضل ألّا تحتاجه |

ولكل جزءٍ ملفاته إن شئت: `"parts": { "shell": { "js": ["house.js"] }, "rahl": { "css": ["reader.css"] } }`.

### الأجزاء

| الجزء | ما هو | الصفحة |
|---|---|---|
| `shell` | الهيكل: شريط العنوان، والشريط الجانبي بالأبواب، وشريط الحالة، ومجلس الدرس | `/desk/` |
| `khizana` | الخزانة | `/khizana/` |
| `bench` | المِنضدة (والإخراج) | `/app/` |
| `muharrir` | المحرِّر | `/muharrir/` |
| `rahl` | الرَّحل والقارئ | `/rahl/` |
| `styles` | الأساليب | `/studio/` |
| `covers` | المجلِّد | `/admin/covers/` |
| `settings` | نافذة الإعدادات | `/admin/` |
| `other` | ما سوى ذلك من صفحات | |

كل بابٍ صفحةٌ في إطارٍ داخل الهيكل (`iframe[data-door="rahl"]`…)، ومن الأصل نفسه: فمودٌ في `shell` يصل إلى صفحات الأبواب كلها إن أراد (`wq.win('rahl')`). و«الطِّراز» نفسه لا يدخله مود، فيبقى منه الإطفاء دائماً.

### الإعدادات

```json
"settings": [
  { "key": "volume", "type": "range", "label": "علوّ الصوت", "min": 0, "max": 1, "step": 0.05, "default": 0.7 },
  { "key": "crackle", "type": "toggle", "label": "طقطقةٌ خافتة", "default": false },
  { "key": "color", "type": "color", "label": "لون اللهب", "default": "#ffb547" },
  { "key": "mode", "type": "select", "label": "الشكل", "options": [{ "value": "oil", "label": "سراج زيت" }, { "value": "candle", "label": "شمعة" }], "default": "oil" },
  { "key": "size", "type": "number", "label": "الحجم", "min": 10, "max": 80, "default": 24, "unit": "نقطة" },
  { "key": "greeting", "type": "text", "label": "التحية", "default": "مرحباً" }
]
```

الأنواع: `toggle` و `range` و `number` و `color` و `select` و `text`، ولكلٍّ `hint` (شرحٌ صغير) إن شئت. القيم في `wq.settings`، وتسري في الحال: إن سجّلتَ `wq.onSettings(fn)` نُودي بها، وإلا أُعيد المود كله بالقيم الجديدة.

## mod.js

ملف JavaScript (وحدة ES) يُصدِّر دالةً تأخذ `wq`، وترجع (إن شئت) دالةً تُنادى حين يُطفأ:

```js
export default function (wq) {
  if (wq.part !== 'shell') return;
  const b = wq.add('<button class="door tool"><span>زرّي</span></button>', '.side');
  wq.on(b, 'click', () => wq.toast('مرحباً!'));
  return () => { /* ما لم تُضفه بأدوات wq تُزيله أنت هنا */ };
}
```

**قاعدةٌ واحدة:** ما تضيفه بأدوات `wq` يزول وحده حين يُطفأ المود (أو يُعاد بعد حفظ ملفاته). فاستعملها، يُطفأ مودك ويُشعل بلا إعادة تحميل.

### أدوات wq

| الأداة | ما تفعل |
|---|---|
| `wq.id` `wq.name` `wq.version` `wq.part` | المود، والجزء الذي يعمل فيه الآن |
| `wq.settings` | قيم الإعدادات |
| `wq.onSettings(fn)` | حين تتغيّر الإعدادات |
| `wq.url('img/x.png')` | عنوان ملفٍ من ملفات المود |
| `wq.css(text)` | يضيف أنماطاً ← عنصر `<style>` |
| `wq.html(markup)` | عنصرٌ من HTML |
| `wq.add(el أو html, مكان?, قبل?)` | يضيف عنصراً (المكان: عنصر أو محدِّد CSS؛ الأصل `body`) ← العنصر |
| `wq.on(عنصر, حدث, fn, خيارات?)` | مستمع ← دالة تُلغيه |
| `wq.on('door' / 'bench' / 'night', fn)` | أحداث البرنامج (تحت) |
| `wq.timeout(fn, ms)` `wq.interval(fn, ms)` | مؤقّتات |
| `wq.frame((t, dt) => …)` | حلقة رسمٍ كل إطار (تتوقف إن رجعت `false`) ← دالة توقفها |
| `wq.observe(عنصر, fn, خيارات?)` | مراقبة تغيّر الصفحة |
| `wq.when(محدِّد)` | ← وعدٌ بأول عنصرٍ يطابق (الآن أو حين يظهر) |
| `wq.each(محدِّد, fn)` | `fn(عنصر)` لكل عنصرٍ يطابق، الآن وكلما ظهر جديد (للصفحات التي تُعاد رسمها). وإن رجعت `fn` دالةً نُوديت حين يُطفأ |
| `wq.sound('a.mp3', {volume, loop, rate})` | يشغّل صوتاً من ملفات المود ← عنصر الصوت |
| `wq.audio` | `AudioContext` للمود |
| `await wq.buffer('a.wav')` ثم `wq.play(buf, {volume, rate, loop})` | صوتٌ بلا تأخير (للنقر والمؤثرات) |
| `wq.store.get(k, أصل)` `wq.store.set(k, v)` | حفظٌ صغيرٌ للمود في الجهاز |
| `wq.toast(نص)` | رسالةٌ قصيرة |
| `wq.door` `wq.doors` `wq.go('rahl')` `wq.win('bench')` | الأبواب: الظاهر، وكلها، وفتح باب، ونافذة باب |
| `wq.night` `wq.setNight(true)` | السِّراج |
| `wq.command({ title, keys?, run })` | أمرٌ في «القلم» (Ctrl+K) |
| `await wq.api('/api/…', {method, body})` | طلبٌ إلى خادم البرنامج الداخلي |
| `wq.shell` `wq.desk` | واجهة الهيكل (`WarraqShell`) وجسر البرنامج (`warraqDesktop`) كما هما: لمن أراد كل شيء |
| `wq.cleanup(fn)` | ما يُفعل حين يُطفأ |
| `wq.log(…)` `wq.error(نص)` | سجلّ أدوات المطوّر، وخطأٌ يُكتب في «الطِّراز» |

### أحداث البرنامج

| الحدث | متى | ما يصل |
|---|---|---|
| `door` | تغيّر الباب الظاهر | `{ door, from }` |
| `bench` | تغيّر ما على المنضدة أو حال إخراجه | `{ id, title, running, pct, stage, done, volumes }` أو `null` |
| `night` | أُوقد السِّراج أو أُطفئ | `true` أو `false` |

### ما في الهيكل (للمودات في `shell`)

| المحدِّد | ما هو |
|---|---|
| `.tbar` | شريط العنوان |
| `.side` | الشريط الجانبي؛ وفيه `.side .door[data-door="khizana"]`… و `.side .sp` (الفراغ قبل الأدوات) |
| `.side [data-lamp]` | زرّ السِّراج (`aria-pressed`) |
| `#settingsBtn` | زرّ الإعدادات |
| `#doors` | مكان الأبواب، وفيه `iframe[data-door="…"]` |
| `.status` | شريط الحالة |
| `#lesson` | مجلس الدرس |

والأبواب: `khizana` و `bench` و `muharrir` و `rahl` و `styles` و `covers` و `tiraz`.

### ألوان البرنامج

متغيّرات CSS في كل صفحة (وتتبع السِّراج: `html.night`):
`--paper` (الورق) و `--vellum` و `--sheet` و `--ink` (الحبر) و `--rubric` (العنابي) و `--gold` و `--gold-d` و `--line` و `--muted` و `--btn` و `--on-rubric`، والخطّان `--display` (العناوين) و `--ui` (الواجهة).

## الحزمة ‎.wqmod‎

ملفٌّ مضغوط (ZIP) لمجلد المود، وفيه `mod.json` في أوله (أو في مجلدٍ واحدٍ داخله). «صدّره للمشاركة» يصنعه لك. ويُقبل فيه: ‎.js .mjs .css .json .html .svg .png .jpg .webp .gif .mp3 .wav .ogg .m4a .webm .mp4 .woff2 .ttf .otf .glb .wasm‎ وأمثالها، حتى ٩٦ م.ب و٣٠٠٠ ملف. ولا يُقبل فيه مسارٌ يخرج منه ولا رابطٌ رمزي.

## إن أفسد مودٌ الواجهة

- **Ctrl+Alt+Shift+M** (أو «عرض ← أوقف المودات كلها») يوقف المودات كلها ويعيد الواجهة، ولو لم يظهر شيءٌ منها.
- وإن توقّفت الواجهة أو لم تستجب والمودات تعمل: تُوقف وحدها (الوضع الآمن)، ويقول «الطِّراز» السبب.
- وتشغيل البرنامج بـ `--safe-mode` يبدأ بلا مودات.

## نصائح

- استعمل `wq.each` و `wq.when` لا `querySelector` وحده: صفحات البرنامج تُرسم بعد تحميلها، وبعضها يُعاد رسمه.
- لا تُطِل العمل في حلقةٍ واحدة (يتجمّد البرنامج)؛ وزّعه على `wq.frame`.
- اجعل الحركة لطيفة، واحترم `prefers-reduced-motion`.
- مودات الورّاق (السراج المتّقد، ودار الورّاق، والورق العتيق) أمثلةٌ كاملة: مصادرها في مجلد «المصادر» مع ملفاتها، أو «افتح مجلده» بعد تثبيته.
